📊 Gen Z Social Media Behavior Analysis
 
📌 Project Overview
 
This project explores social media usage patterns among Gen Z users using a large-scale dataset of 1 million records. The goal was to uncover behavioral trends, platform preferences, and the relationship between social media usage and mental health.
 
---
 
🎯 Objectives
 
- Analyze which platforms drive the highest engagement
- Understand how multi-platform usage affects total screen time
- Study demographic patterns (age, gender, country)
- Examine the relationship between usage behavior and mental health
- Identify patterns in highly active and highly addicted users
 
---
 
🛠️ Tools & Technologies
 
- Python
- Pandas (data cleaning & analysis)
- NumPy
- Matplotlib / Seaborn (visualization)
- Jupyter Notebook
 
---
 
📂 Dataset Features
 
- Age, Gender, Country
- Daily Usage Hours
- Primary Platform
- Number of Platforms Used
- Purpose (Education, Entertainment, etc.)
- Average Session Duration
- Night Usage
- Mental Health Score
- Addiction Level
- Screen Time Before Sleep
 
---
 
🔍 Key Analysis Performed
 
1. Platform Engagement
 
- Identified platforms with highest daily usage
- Compared engagement across Instagram, TikTok, YouTube, etc.
 
2. Multi-Platform Behavior
 
- Analyzed whether users spend more time when using multiple platforms
- Found patterns in attention distribution
 
3. Demographic Insights
 
- Compared usage across countries and genders
- Identified minimal variation across demographics
 
4. Addiction & Behavioral Patterns
 
- Segmented users based on addiction level
- Analyzed night usage and screen time before sleep
 
5. Mental Health Analysis
 
- Compared mental health scores across usage levels and purposes
- Explored impact of heavy usage
 
---
 
📊 Key Insights
 
- 📱 Top Platforms Dominate Attention
  Instagram, YouTube, and TikTok account for the majority of user engagement.
 
- 🔄 Multi-platform users split attention
  Using more platforms does not increase total usage time — users distribute time instead.
 
- 🌍 Demographics have limited impact
  Usage patterns are consistent across countries and genders.
 
- 🌙 High usage is linked to behavioral patterns
  Heavy users show increased night usage and higher screen time before sleep.
 
- 🧠 Mental health shows slight decline with higher usage
  Higher screen time correlates with lower mental health scores.
